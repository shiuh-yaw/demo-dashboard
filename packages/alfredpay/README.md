# @dynamic-demos/alfredpay

Direct REST integration for alfredPay (LATAM payment processor: BR, MX, CO,
AR, SV, US).

The Fireblocks-mediated DVP path for the same partner lives at
`packages/fireblocks/src/providers/alfredpay.ts` (per `DECISIONS.md` D-009 —
provider package boundary is by API mechanism, not partner brand).

For local context, capabilities, env, and integration notes see
[`AGENTS.md`](./AGENTS.md). For the source of truth on the API itself see
the alfredPay docs:

- https://alfredpay.io/documentation
- https://alfredpay.readme.io
