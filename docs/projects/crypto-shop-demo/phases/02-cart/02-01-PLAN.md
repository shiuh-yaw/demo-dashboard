Create `apps/shop/lib/cart-context.tsx` with:

1. **Types** (all in same file):
```typescript
export interface CartItem {
  product: Product;  // import from @/data/products
  quantity: number;
}

type CartAction =
  | { type: "ADD_ITEM"; product: Product }
  | { type: "REMOVE_ITEM"; productId: string }
  | { type: "INCREMENT"; productId: string }
  | { type: "DECREMENT"; productId: string }
  | { type: "CLEAR" };

interface CartState {
  items: CartItem[];
}

interface CartContextValue {
  items: CartItem[];
  addItem: (product: Product) => void;
  removeItem: (productId: string) => void;
  increment: (productId: string) => void;
  decrement: (productId: string) => void;
  clearCart: () => void;
  totalItems: number;
  totalPrice: number;
}
```

2. **Reducer function** `cartReducer(state: CartState, action: CartAction): CartState`:
   - `ADD_ITEM`: If product already in cart, increment its quantity. Otherwise push new CartItem with quantity 1.
   - `REMOVE_ITEM`: Filter out the item with matching productId.
   - `INCREMENT`: Map over items, increment quantity of matching productId.
   - `DECREMENT`: Map over items, decrement quantity of matching productId. If quantity reaches 0, remove the item.
   - `CLEAR`: Return `{ items: [] }`.

3. **CartProvider component**: Uses `useReducer(cartReducer, { items: [] })`. Computes `totalItems` as `items.reduce((sum, item) => sum + item.quantity, 0)` and `totalPrice` as `items.reduce((sum, item) => sum + item.product.price * item.quantity, 0)`. Memoize context value with `useMemo`. Must have `"use client"` directive at top.

4. **useCart hook**: `useContext(CartContext)` with throw if used outside provider.

5. **Export**: `CartProvider` and `useCart`.
