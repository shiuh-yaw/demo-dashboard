## What needs to happen

### 1. Create `.github/workflows/ci.yml`

Triggers: every PR to main, every push to main.

Jobs (parallelizable where possible):

- **install**: `pnpm install --frozen-lockfile`. Cache pnpm store + node_modules. Set up Turbo remote cache (use Vercel remote cache via `TURBO_TOKEN`/`TURBO_TEAM` if available; fall back to local cache).
- **typecheck**: `pnpm turbo typecheck`.
- **lint**: `pnpm turbo lint`.
- **build**: `pnpm turbo build`.
- **test**: `pnpm turbo test`.

Each job depends on `install`. Use Node 20 (matches monorepo `package.json` engines if set; otherwise 20.x LTS).

Write it as one workflow file, idiomatic GitHub Actions, using `pnpm/action-setup`.

### 2. Create `.github/workflows/spark26-protection.yml`

Triggers: every PR to main.

Single job: parses the PR diff. Fails the workflow if any file under `apps/spark26/` is modified AND the PR title does not contain `[spark26]`.

Implementation: bash, no external dependencies. Use `${{ github.event.pull_request.title }}` and `git diff --name-only origin/${{ github.base_ref }}...HEAD`.

Example skeleton (adapt as needed):

```yaml
name: spark26 protection
on:
  pull_request:
    branches: [main]

jobs:
  enforce:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0
      - name: Block accidental spark26 changes
        env:
          PR_TITLE: ${{ github.event.pull_request.title }}
        run: |
          CHANGED=$(git diff --name-only origin/${{ github.base_ref }}...HEAD)
          if echo "$CHANGED" | grep -q "^apps/spark26/"; then
            if [[ "$PR_TITLE" != *"[spark26]"* ]]; then
              echo "::error::PRs modifying apps/spark26/ require [spark26] in PR title (deliberate opt-in for prod app)."
              exit 1
            fi
          fi
```

### 3. Add a sandbox/prod credential guardrail to `ci.yml`

A job step (not a separate workflow) that grep-fails if any `apps/<name>/` env reference contains `_PRODUCTION` keys without `[prod-creds]` in the PR title.

```yaml
- name: Block production credentials in apps without [prod-creds] in title
  if: github.event_name == 'pull_request'
  env:
    PR_TITLE: ${{ github.event.pull_request.title }}
  run: |
    if grep -rn "PRODUCTION" apps/*/env* apps/*/.env* 2>/dev/null | grep -v 'spark26'; then
      if [[ "$PR_TITLE" != *"[prod-creds]"* ]]; then
        echo "::error::Production credentials referenced in apps/* without [prod-creds] in PR title."
        exit 1
      fi
    fi
```

(Adapt the grep target to actual env file conventions in this repo. Test that it doesn't false-positive on existing files.)
